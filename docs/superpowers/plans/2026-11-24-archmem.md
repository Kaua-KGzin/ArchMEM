# ArchMEM Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Turn the Simuler-Mem demo into ArchMEM, a step-by-step virtual-memory lab for OS students, with one C engine shared by a CLI and a WebAssembly web app.

**Architecture:** A pure C11 library (`core/`) exposes one JSON boundary, `archmem_run(request) -> response`. The native CLI (`cli/`) and the WASM build both call it. A static TypeScript + Vite site (`web/`) renders the per-step event log the engine returns, and is deployed to Vercel with arch-deploy.

**Tech Stack:** C11 (gcc/clang/MinGW), Emscripten (emsdk latest), Node 24, TypeScript + Vite (no UI framework), GitHub Actions, arch-deploy v2.0.0, Vercel.

**Spec:** `docs/superpowers/specs/2026-11-24-archmem-design.md`

## Global Constraints

- C11, `-Wall -Wextra -Wpedantic -Werror`, no third-party C code, no globals with mutable state, no `printf` in `core/`.
- Deterministic: own PRNG (xorshift32); same request -> byte-identical JSON native and WASM.
- All UI text in Portuguese; engine emits `why` keys, the UI owns the wording.
- Algorithm conventions exactly as the spec's "Modelo de simulação" (Silberschatz): Clock loads with ref=1, hand starts at frame 0, stops after the replaced frame, hit sets bit without moving hand; LFU counts while resident, starts at 1, tie -> oldest loaded; OPT tie -> lowest page; free frames used in ascending order.
- Limits (reject with `{"ok":false,"error":...}`, never crash): refs 1..10000; frames 1..64; virtual_pages 1..4096; page_size power of two 16..65536; tlb_entries 0..64; max_frames (curve) 1..64; seg memory_size 1..1048576, ops <= 1000.
- Product identity: name `ArchMEM`, id `archmem`, role `insight`, runtime `static`, version `2.0.0`, URL `https://archmem.vercel.app`, health `/health`.
- Nothing in the product reads or writes another process's memory.

## Review Focus

1. Malformed `refs` (`"7 x 1"`, `"-3"`, `"@0xZZ"`, empty) -> `ok:false` with the offending token in `error`, no crash (Task 2 test `test_refs_errors`).
2. A page or address outside the virtual space -> error naming the step, not silent wraparound (Task 3 test `test_out_of_range`).
3. `frames >= distinct pages` -> zero replacements and `victim:null` on every step (Task 3 test `test_no_replacement_when_enough_frames`).
4. Write on a hit must set dirty and cause a write-back when that page is later evicted; TLB entry of an evicted page must be invalidated (Task 3 tests `test_dirty_writeback`, `test_tlb_invalidated_on_evict`).
5. Huge or hostile web input (10000 refs, hash with garbage) -> UI shows the engine error and stays usable (Task 11 test `hash with garbage falls back to default scenario`).

## JSON contract (shared by every task)

Requests always carry `"action"`. Errors: `{"ok":false,"error":"<message pt-BR>"}`.

```jsonc
// run
{"action":"run",
 "config":{"page_size":64,"frames":3,"virtual_pages":16,"tlb_entries":0,"algorithm":"lru"},
 "refs":"7 0 1 2w @130 @0x82w"}          // N = page N read, Nw = write, @A = address (dec or 0x)
-> {"ok":true,"algorithm":"lru",
    "totals":{"accesses":20,"faults":12,"hits":8,"hit_rate":0.4,"replacements":9,
              "writebacks":0,"tlb_hits":0,"tlb_misses":0},
    "steps":[{"step":1,"op":"R","address":448,"page":7,"offset":0,
              "tlb":"off|hit|miss","result":"hit|fault","frame":0,
              "victim":null | {"page":2,"frame":1,"dirty":false},
              "why":"<key>","why_args":{...},
              "frames":[{"page":7,"ref":1,"count":1,"loaded":1,"last":1,"dirty":false} | null, ...],
              "hand":0,"tlb_pages":[7]}]}
// why keys: hit, hit_tlb, fault_free_frame, fault_evict_fifo, fault_evict_lru,
//   fault_evict_clock, fault_evict_lfu, fault_evict_opt
// why_args for evictions: {"victim":2,"loaded":3,"last":4,"count":1,"next_use":-1,"cleared":[pages whose ref bit Clock cleared]}

// compare
{"action":"compare","config":{...},"algorithms":["fifo","lru","clock","lfu","opt"],"refs":"..."}
-> {"ok":true,"results":[{"algorithm":"fifo","totals":{...}}, ...]}

// curve
{"action":"curve","config":{...},"algorithms":[...],"max_frames":8,"refs":"..."}
-> {"ok":true,"frames":[1,2,...,8],"series":[{"algorithm":"fifo","faults":[...]}],
    "belady":[{"algorithm":"fifo","at_frames":4}]}   // frames where faults rose vs frames-1

// gen
{"action":"gen","kind":"uniform|locality|loop|sequential","length":50,"pages":10,"seed":42,"write_ratio":0.0}
-> {"ok":true,"refs":"3 7 7 1 ..."}

// seg
{"action":"seg","memory_size":1024,"fit":"first|best|worst","ops":"alloc A 300; alloc B 600; free A; alloc C 120"}
-> {"ok":true,"steps":[{"step":1,"op":"alloc","name":"A","size":300,"result":"ok|fail",
     "base":0,"chosen_hole":{"base":0,"size":1024},"candidates":[{"base":0,"size":1024}],
     "why":"seg_first_fit|seg_best_fit|seg_worst_fit|seg_free|seg_fail_fragmentation|seg_fail_no_space",
     "map":[{"base":0,"size":300,"name":"A"},{"base":300,"size":724,"name":null}]}],
    "totals":{"free":724,"largest_hole":724,"holes":1,"failures":0,"external_fragmentation":0.0}}
// external_fragmentation = 1 - largest_hole/free (0 when free == 0)

// challenge
{"action":"challenge","seed":7,"difficulty":1}
-> {"ok":true,"challenge":{"kind":"faults|victim|best_algorithm","params":{...},
     "scenario":{"config":{...},"refs":"..."},"answer":<int|string>}}
```
